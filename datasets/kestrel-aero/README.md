# Kestrel Aero Components

**Industry:** Aerospace machining

A made-up machine shop in Red Mesa. Hangar 2 cuts titanium; Shop 6 cuts aluminum. 2018 vs 2025 spec letters disagree.

Fictional on purpose (ADR 003 / ADR 010). Not a real company. 16 notes, 18 gold
questions. `ka-017` and `ka-018` are recovery-oriented (issue #32): they ask
about the current titanium traveler without naming the 2025 sheet.
